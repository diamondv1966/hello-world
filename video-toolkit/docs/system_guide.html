3Skills ที่ลงทะเบียนแล้ว (9 สกิล)

อยู่ใน .claude/skills/<ชื่อ>/SKILL.md และ Claude Code โหลดเองเมื่อเปิดเซสชันใน repo นี้ แต่ละสกิลมีค่าตัวเลข คำสั่ง และกติกาที่นำไปใช้ได้ทันที

⚡ edit-like-reference (โหมดหลัก)
หย่อนคลิป + บอกเรฟ (ไฟล์วิดีโอ / ชื่อครีเอเตอร์ / preset) → วิเคราะห์สไตล์เรฟ → auto-edit → Claude ทำ creative pass (แก้ซับ, hook, คำเน้น, การ์ด, CTA) → QA → ไฟล์พร้อมโพสต์
🎬 video-clip-analysis
รับคลิป (ยืนยันชื่อไฟล์และ SHA-256), ถอดเสียง, หาช่วงเงียบ, วัดค่า, ดูท่าทาง แล้วทำแผน 12 หัวข้อ รวมถึงกติกาการตัดและการตรวจคุณภาพ
✍️ onscreen-text-animation
จานสี (HEX + รหัส ASS), ขนาดและตำแหน่งใน safe zone, สูตรอนิเมชัน CapCut และ ASS (pop, typewriter, wipe, pulse)
🖼️ broll-image-research
จุดแทรกหลังท่าเด่น, คำค้น 2 ภาษา, สไตล์ภาพ, กรอบการ์ด, การ์ดที่วาดเอง 6 แบบ
🔊 sound-design
คลัง uisfx 12 แนว, ตารางบทบาทของเสียง, ระดับ dB, จังหวะวาง, ชุดคำสั่งปรับเสียงพูด และ cue sheet
🎵 music-direction
ตารางเลือกอารมณ์และ BPM ตามเนื้อหา, ระดับเสียง + ducking, ไดนามิกตามโครงสร้าง, เพลงต้นฉบับ
🛠️ capcut-ffmpeg-workflow
CapCut 13 ขั้น + pipeline FFmpeg + การตรวจคุณภาพ + ปัญหาที่พบบ่อย
📄 system-docs-pdf
แปลง HTML เป็น PDF ด้วยฟอนต์ Kanit, กติกาการจัดหน้า และการตรวจภาพทุกหน้า
🔎 trend-research
วิธีค้นและให้น้ำหนักแหล่ง, บันทึกผลพร้อมวันที่และ URL (references/trends-2026-11.md)
กติกาประจำ repo อยู่ใน CLAUDE.md (โหลดทุกเซสชัน) ได้แก่ ลำดับบังคับ (เตรียมระบบ → ยืนยันไฟล์ → ห้ามใช้ข้อมูลคลิปเก่า), มาตรฐาน และแผนผังว่าบทบาทไหนใช้สกิลไหน

4สิ่งที่ต้องมี / สิ่งที่เตรียมไว้แล้ว

ส่วนประกอบสถานะรายละเอียด
FFmpeg 6.1 (libass, harfbuzz, x264)✅ พร้อมตัดต่อ ใส่ข้อความไทย ซูม ปรับสี มิกซ์เสียง
Python 3.13 + faster-whisper✅ พร้อมถอดเสียงไทย
โมเดล Whisper small (int8)✅ พร้อมดาวน์โหลดจาก npm และตรวจ SHA-256 แล้ว (HuggingFace ถูกบล็อก)
Pillow + raqm, numpy, fonttools✅ พร้อมวาดการ์ดและกราฟิกภาษาไทย สังเคราะห์เพลงและเสียง
ฟอนต์ Kanit Regular / ExtraBold✅ พร้อมไทยและอังกฤษรวมในไฟล์เดียว (OFL)
Noto Color Emoji✅ พร้อมไอคอนและภาพในการ์ด
เอฟเฟกต์เสียง uisfx (CC0)✅ พร้อม12 แนว × 78 เสียง ใช้เชิงพาณิชย์ได้
Chromium + Playwright✅ พร้อมใช้ทำไฟล์ PDF
Skills 9 ตัว + Agents 10 ตัว + CLAUDE.md✅ พร้อมอยู่ใน .claude/ ของ repo และโหลดอัตโนมัติ
WebSearch / WebFetch✅ พร้อมใช้ค้นคว้าเทรนด์และสเปก (ทดสอบแล้ว)
เว็บ Stock (Pexels, Pixabay, Mixkit, Freesound)⚠️ ถูกบล็อกใช้ภาพประกอบที่วาดขึ้นเองแทน หรือส่งไฟล์ B-roll มาให้

5วิธีค้นคว้า (Research & Trend)

  1. ใช้ WebSearch แบบ standard ก่อน และค้นหลายคำถามพร้อมกัน (เทรนด์ + สเปก + เสียง)
  2. ให้น้ำหนักแหล่ง: เอกสารทางการ > ข้อมูลจำนวนมาก/งานวิจัย > บล็อกของผู้ขายเครื่องมือ
  3. ถ้าตัวเลขจากแหล่งต่าง ๆ ขัดกัน ให้ใช้ค่าอนุรักษ์นิยมและระบุช่วงค่า
  4. บันทึกผลพร้อมวันที่และ URL ลงไฟล์ references แล้วให้ Skill Builder อัปเดตสกิลถ้ามาตรฐานเปลี่ยน

ผลค้นคว้าล่าสุด (14 พ.ย. 2026)

เรื่องข้อค้นพบผลต่อมาตรฐานทีม
Hook / Retentionretention เป็นสัญญาณหลักของอัลกอริทึม คนดูตัดสินใจภายในประมาณ 2 วินาที และการทิ้งประเด็นค้างไว้ (open loop) ช่วยให้ดูต่อข้อความ Hook ขึ้น ≤0.3 วินาที, ใช้ progress bar และเกริ่นตอนต่อไป
แคปชั่นคำพูด ข้อความบนจอ และแคปชั่นควรตรงกัน ใช้แคปชั่นอัตโนมัติร่วมด้วยข้อความบนจอใช้คำเดียวกับที่พูด
Safe zoneไม่มีสเปกทางการ แหล่งต่าง ๆ ระบุพื้นที่ที่ถูกบังไว้ที่ บน 108–154px, ล่าง 250–480px, ขวาประมาณ 150pxบน 130 · ล่าง y≤1440 · ขวา x≤930 การ์ดอยู่ในช่วง y 1000–1420
Loudnessค่าที่ใช้กันมากคือ -14 LUFS / -1 dBTP (บางแหล่ง -13 หรือ -16) และเพลงเบากว่าเสียงพูด 12–18 dBคงไว้ที่ -14 LUFS, peak ≤ -1.5, เพลงเบากว่าเสียงพูด 17–20 dB + ducking

6มาตรฐานคุณภาพคลิป

⚡ จังหวะ
  • Hook แรงใน 3 วินาทีแรก (ข้อความขึ้นภายใน 0.3 วินาที)
  • ตัดช่วงเงียบที่ยาวเกิน 0.2–0.3 วินาที
  • ตัดคำที่พูดผิด พูดซ้ำ หรือไม่จำเป็น
  • ความยาว 35–55 วินาที
🎨 ภาพและข้อความ
  • โทนสี ฟ้าอ่อน → น้ำเงิน → ชมพูอ่อน
  • มีภาพประกอบในประเด็นสำคัญ
  • มีอนิเมชันที่ช่วยเน้นประเด็น ใช้เวลาเข้าไม่เกิน 0.3 วินาที
  • กราฟิกไม่บังหน้า ท่าทางเด่น หรือ UI ของ TikTok (safe zone: บน 130, ล่าง y≤1440, ขวา x≤930)
🔊 เสียง
  • เสียงพูดชัด: ลดเสียงรบกวน, EQ, ลดเสียง "ซ", คอมเพรส
  • เพลงเบากว่าเสียงพูด 17–20 dB และเบาลงเองเวลามีคนพูด
  • มาสเตอร์ -14 LUFS / peak ≤ -1.5 dBFS
✅ ส่งมอบ
  • MP4 1080x1920 30fps H.264 + AAC
  • ภาพปก แคปชั่น และแฮชแท็ก
  • สื่อทั้งหมดไม่ติดลิขสิทธิ์ (CC0 / สร้างขึ้นเอง / OFL)
  • คลิปสุขภาพต้องมีคำเตือนทางการแพทย์

1 รับคลิปnew_project.sh: ยืนยันชื่อไฟล์, SHA-256 และความละเอียด และเตือนถ้าเป็นคลิปซ้ำprojects/<ชื่อ>/src.mp4
2 วิเคราะห์ถอดเสียง, หาช่วงเงียบ, วัดเสียงและสี, ดูท่าทางทุก 0.5 วินาทีtranscript, รายการช่วงเงียบ, ค่าที่วัดได้
3 วางแผนจุดตัด, โครงสร้าง, ข้อความ, B-roll, กราฟิก, เสียง, เพลง, สี, CapCutคู่มือ 11 หัวข้อ (.md)

5 ตรวจคุณภาพดูเฟรมที่สุ่มมา (กราฟิกบังหน้าไหม), วัด LUFS และ peak, เช็กความยาวแก้ไขแล้ว render ซ้ำ
6 ส่งมอบวิดีโอ ภาพปก แคปชั่น การ์ด PNG ชุดเอฟเฟกต์เสียง และคู่มือไฟล์พร้อมโพสต์
หลักวางภาพประกอบ: ให้การ์ดขึ้นหลังท่าทางเด่น (เช่น จับหัว หรือแกล้งหาว) และตรงกับตอนพูดคำสำคัญ เช่น "ขาด…" หรือ "เสี่ยง…" วางไว้ครึ่งล่างของจอ ถ้าหน้าลงมาต่ำ ให้ปรับจุดซูมให้หน้าอยู่สูงขึ้น

10เคล็ดลับสำคัญ

🔒 บังคับให้ใช้คลิปใหม่: เขียนในข้อความว่า "นี่คือคลิปใหม่ ชื่อไฟล์ ___ ห้ามใช้ข้อมูลจากคลิปก่อนหน้า" ระบบจะตรวจ SHA-256 ทุกครั้ง ถ้าไฟล์ซ้ำกับที่เคยส่งมาจะแจ้งทันที ป้องกันการแนบผิดไฟล์ (ชื่อไฟล์ที่ลงท้ายเหมือนกันไม่ได้แปลว่าเป็นคลิปเดียวกัน ระบบเทียบจากเนื้อไฟล์)
💾 เซสชันคลาวด์ถูกล้างได้: เครื่องมืออยู่ใน repo (video-toolkit/) และติดตั้งใหม่ได้ด้วย ./setup.sh ภายในไม่กี่วินาที ส่วนวิดีโอที่ได้ ให้ดาวน์โหลดเก็บไว้ทันที (ไฟล์วิดีโอไม่ได้ถูก commit เพราะไฟล์ใหญ่)
🖼️ B-roll จริง: เว็บ Stock ถูกบล็อกจากเครื่องคลาวด์ ให้ดาวน์โหลดตามคำค้นในหัวข้อ 6 แล้วแนบมา หรือให้ระบบวาดการ์ดภาพประกอบให้ ซึ่งไม่ติดลิขสิทธิ์
🎧 ฟังก่อนโพสต์เสมอ: AI ตรวจจากค่าความดังและเฟรมภาพ แต่ฟังเสียงเองไม่ได้ ควรเปิดดูและฟังหนึ่งรอบก่อนโพสต์
🩺 คลิปสุขภาพ: ใส่คำเตือน "ข้อมูลเบื้องต้น ไม่ใช่การวินิจฉัย" และเช็กข้อมูลบนการ์ด (ตัวเลข เกณฑ์) ก่อนโพสต์
