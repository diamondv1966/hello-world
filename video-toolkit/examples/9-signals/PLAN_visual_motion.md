## 1. สรุปคลิป
- **เนื้อหา:** ลิสต์ 9 อาการที่บอกว่าร่างกายขาดอะไร ปิดด้วยการเกริ่นตอนต่อไป (วิธีป้องกัน) และชวนไลก์ แชร์ ซับสไครบ์

- **จุดอ่อน:** เงียบ 3 วินาทีแรก, ฉากเดียว กล้องนิ่ง, ภาพ 540p, เสียงเบา (-22.9 LUFS), ข้อมูลเป็นนามธรรม (ขาดแมกนีเซียม, B12) คนดูนึกภาพตามไม่ออก **จึงต้องใช้ภาพประกอบช่วย**

## 6. ภาพประกอบ / B-roll + คำค้นหา
**สไตล์รวม:** soft pastel + clean (พื้นขาว ฟ้า ชมพู, แสงสว่างนุ่ม, ไม่ใช้ภาพแผล ภาพเลือด หรือภาพที่ดูน่ากลัว)
**รูปแบบวาง:** การ์ดมุมมนรัศมี 36px ขอบขาว 8px + เงา navy 30% ขนาด 46% ของจอ (≈500x500) วางขวากลาง (x≈540–1040, y≈620–1120) ข้างหน้า ไม่บังปาก

## 11. สรุปขั้นตอนที่ต้องทำใน CapCut
1. **ตั้งโปรเจกต์:** New project → นำเข้าคลิป → Canvas 9:16 → ตั้ง Resolution 1080p
2. **ตัด:** Split ตามตารางหัวข้อ 3 แล้วลบช่วงเงียบ (หรือใช้ Auto cut → Remove pauses แล้วเช็กกับตาราง)
3. **เสียงพูด:** แตะคลิป → Audio → Enhance voice เปิด, Reduce noise เปิด, Normalize loudness เปิด
4. **ซูม:** ใส่ Keyframe ต้นและท้ายของแต่ละช่วงตามหัวข้อ 4 ทุกจุดที่ตัดกลางประโยคให้ Scale +6% ทันที
5. **ปรับสี:** Adjust ตามหัวข้อ 10 → Apply to all
6. **ข้อความ:** Text → Add text → ฟอนต์ Kanit (หรือ Prompt) → ตั้งสีและขอบตามหัวข้อ 5 → Animation In: "Slide up / Pop / Typewriter / Wipe" ตามตาราง (Duration 0.2–0.3s) → บันทึกเป็น Text template เพื่อใช้ซ้ำทุกข้อ
7. **Progress bar:** Overlay → Shape (สี่เหลี่ยม) → Keyframe ความกว้างเพิ่มทีละ 1/9 ตอนต้นแต่ละข้อ
8. **B-roll:** Overlay → Add overlay → วางตามเวลาในหัวข้อ 6 → Mask: Rectangle (ปรับมุมมน) → Stroke ขาว 8 → Shadow → Animation In: "Slide right" + Combo: "Zoom in slightly" → Out: "Fade out" → ตรวจว่าไม่ทับท่าจับหัว (0:06.1), จับจมูก (0:25.7), หาว (0:30.6), จับหู (0:36.0)
9. **ไอคอนและกราฟิก:** Sticker → ค้นหา "water drop / heart / ear / bell" หรือใช้ภาพ PNG → Animation In: Pop → Loop: "Float"
10. **ตาราง 3x3 ช่วงเกริ่นตอนต่อไป:** วาง sticker 9 ตัว ตั้ง Delay ห่างกัน 0.08s
11. **เอฟเฟกต์เสียง:** Audio → Sound effects → วางตามหัวข้อ 8 ตั้ง Volume 20–45% ตามระดับ dB
12. **เพลง:** Audio → Music → เลือกแนว lo-fi / chill pop → Volume 10% → Auto ducking เปิด → Fade out 2s
13. **ตรวจเฟรม:** เปิด Safe zone overlay (TikTok) ดูว่าข้อความไม่อยู่ใต้ปุ่มด้านขวาหรือแคปชั่นด้านล่าง
14. **Export:** 1080p · 30fps · Bitrate สูง → ตั้งปกเป็นเฟรม "เตือนคุณ!"
