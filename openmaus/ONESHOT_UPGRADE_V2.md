# ใบสั่งงาน One-shot: อัปเกรดทีมเป็น V2

เจ้าของอนุมัติใบสั่งนี้ทั้งฉบับแล้ว ทำตามลำดับจนจบ หยุดเฉพาะจุดที่เขียนว่า "หยุด"
กติกาเดิมทั้งหมดใน openmaus/TEAM_SETUP.md ส่วนที่ 0 ยังใช้อยู่ (ห้ามแก้โค้ด ห้ามโพสต์ก่อนอนุมัติ)

## สิ่งที่เปลี่ยนใน V2
1. ตัดช่วงเงียบ: ตัดความเงียบหัว-ท้ายของเสียงทุกประโยค เว้นหายใจ 0.12 วินาที ไม่เติมความเงียบให้ครบ 15 วินาทีแล้ว (ใช้บทที่ยาวขึ้นแทน)
2. คลิปไม่ซ้ำ: 3 สไตล์ภาพ (framed / wide / quickcut) x 4 ธีมสี (shopee / night / mint / berry) ระบบเลือกให้ต่อคลิป
3. B-roll AI เล่าเรื่อง: ระบบเขียน broll_prompts.txt ต่อสินค้า ถ้าวางคลิปใน media/<id>/clips/ ระบบแทรกระหว่างรูปจริงเอง
4. เสียงพากย์สำรอง: ถ้าเสียงหลักล้ม ระบบลองเสียงอื่นเองทั้งคลิป (ไม่ปนเสียงในคลิปเดียว)
5. เรียนรู้ตัวเอง: data/learning/ (playbook, lessons, weights) + คำสั่ง python aff.py learn และ python aff.py lesson

## ขั้น 1 — อัปเดตโค้ดและคำสั่งระบบ
1. cd C:\shopee-affiliate แล้ว git pull
2. python -m unittest tests/test_pipeline.py ต้องขึ้น OK (17 tests) และ python aff.py doctor ต้องผ่าน
3. อ่าน openmaus/LEARNING_LOOP.md และ openmaus/QUALITY_STANDARD.md (ตรวจคลิปเพิ่มเป็น 10 ข้อ)
4. อัปเดตคำสั่งระบบของ shopee-producer (ส่วนที่ 0 + ส่วนที่ 2) และ shopee-analyst (ส่วนที่ 0 + ส่วนที่ 4) ตาม openmaus/TEAM_SETUP.md ล่าสุด
   ถ้าแก้คำสั่งระบบเองไม่ได้ ให้แนบข้อความใหม่ในรายงานให้เจ้าของวาง

## ขั้น 2 — บันทึก feedback ของเจ้าของวันนี้
python aff.py lesson "ช่วงเงียบระหว่างประโยคเยอะเกินไป ต้องกระชับ" --tag video --source owner
python aff.py lesson "คลิปเป็นแค่การแปะภาพ อยากให้ไม่ซ้ำกันและเล่าเป็นเรื่อง" --tag video --source owner

## ขั้น 3 — ทำชุดวันนี้ใหม่ (ยังไม่ได้อนุมัติ)
1. เปิด out/<วันนี้>/plan.json จดรหัสสินค้า (id) ทั้ง 5 ชิ้น
2. เขียนบทใหม่ทั้ง 5 ชิ้น (บทยาวขึ้น + broll_prompts): python aff.py generate --id <id> --force ทีละชิ้น
   ถ้าขึ้น "Gemini free quota used up" ให้รอ 60 นาทีแล้วทำต่อ
3. python aff.py daily --count 5
4. ตรวจทุกชิ้นตาม QUALITY_STANDARD.md (ตรวจคลิป 10 ข้อ + ตรวจข้อความ 6 ข้อ)
   - ดูคอลัมน์ "ยาว" ใน APPROVAL.md ชิ้นที่สั้นกว่า 15 วินาที: generate --id <id> --force ใหม่ 1 ครั้ง แล้ว daily ใหม่
   - เทียบกับคลิปชุดเดิม: ช่วงเงียบหายไปจริงไหม แต่ละชิ้นดูต่างกันไหม
5. บันทึกบทเรียนจากการตรวจอย่างน้อย 1 ข้อ: python aff.py lesson "..." --tag video --evidence <ไฟล์> --source shopee-producer

## ขั้น 4 — B-roll AI ทดลอง 1 ชิ้น → หยุด (จุดที่ 1)
ถามเจ้าของในแอป Maus ว่า "มีเครื่องมือทำคลิป AI จากรูป (image-to-video) แบบฟรีที่ล็อกอินไว้ให้ใช้ไหม ชื่ออะไร"
- เจ้าของตอบชื่อเครื่องมือ → ทำ B-roll ให้ชิ้นที่ 1 ตามกติกา B-roll ใน LEARNING_LOOP.md
  (ใช้รูปสินค้าจริงรูปที่ 1 + prompt จาก broll_prompts.txt, เพี้ยนจากของจริง = ทิ้ง, ห้ามจ่ายเงิน)
  บันทึกเป็น media/<id>/clips/broll_1.mp4 แล้ว python aff.py daily --count 5 ใหม่
- เจ้าของตอบว่าไม่มี หรือเครื่องมือขอให้จ่ายเงิน/สมัครแพ็กเกจ → ข้ามขั้นนี้

## ขั้น 5 — ขออนุมัติ → หยุด (จุดที่ 2)
ส่งชุดอนุมัติใหม่แบบเดิม (ตาราง APPROVAL.md ซึ่งตอนนี้มีคอลัมน์ ภาพ/ธีม และ ยาว + image.jpg + video.mp4 ทุกชิ้น + ผลตรวจ 16 ข้อ)
เพิ่มหัวข้อ "เทียบกับชุดเดิม": ความยาวก่อน/หลัง และสิ่งที่เปลี่ยน
หลังเจ้าของตอบ ทำตามขั้น 6 ของ One-shot แรกเหมือนเดิม และบันทึกคำติชมของเจ้าของเป็น lesson --source owner
