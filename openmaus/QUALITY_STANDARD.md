# มาตรฐานงาน (ใช้ทั้งทีม)

งานจริงต้องใช้ **รูปสินค้าจริงจากหน้าสินค้า Shopee** และ **ข้อมูลจริงจากหน้าสินค้า/รีวิวจริง** เท่านั้น
คลิปตัวอย่างที่ Claude Code ทำตอนพัฒนาระบบใช้รูปจำลอง เพื่อทดสอบรูปแบบซับเท่านั้น ห้ามนำไปโพสต์

## รูปสินค้า (scout เก็บ / producer ตรวจ)

1. เก็บ 3-5 รูปต่อสินค้า เรียงลำดับดังนี้
   - รูปที่ 1 (ปกคลิปและภาพโพสต์): ตัวสินค้าเต็มชิ้น ชัด พื้นหลังสะอาด
   - รูปที่ 2-3: มุมอื่น รายละเอียด วัสดุ หรือขนาดเทียบ
   - รูปที่ 4-5: ตอนใช้งานจริง หรือของที่ได้ในกล่อง (ถ้ามี)
2. ใช้ที่อยู่รูปขนาดเต็ม: คลิกขวาที่รูปใหญ่ในหน้าสินค้า > คัดลอกที่อยู่รูปภาพ
   ถ้าลิงก์ลงท้ายด้วย `_tn` คือรูปย่อ ระบบจะตัด `_tn` ออกให้เองตอน import
3. ไม่เอารูปที่:
   - ด้านสั้นเล็กกว่า 600 px (ระบบเตือนและไม่ใช้รูปที่เล็กกว่า 500 px)
   - มีราคา ป้ายลดราคา หรือวันที่โปรโมชันเขียนอยู่ในรูป (ราคาเปลี่ยนได้ คลิปจะกลายเป็นข้อมูลผิด)
   - เป็นภาพตัดต่อหลายรูปในรูปเดียวที่มีตัวหนังสือเต็ม
   - มีโลโก้หรือลายน้ำของร้านอื่นหรือแพลตฟอร์มอื่น
   - ไม่ใช่สินค้าชิ้นนั้น (สีหรือรุ่นอื่น) ถ้าสินค้ามีหลายสี ใช้สีหลักสีเดียวทั้งคลิป
4. ถ้ารูปที่ผ่านเกณฑ์มีน้อยกว่า 3 รูป ให้เก็บเท่าที่มี (อย่างน้อย 2) และเขียนในหมายเหตุ

## ข้อมูลสินค้า (scout)

- จุดเด่น: คัดจากรายละเอียดสินค้าของร้าน เฉพาะข้อเท็จจริงที่ตรวจได้ (ขนาด วัสดุ จำนวน กำลังไฟ ความจุ) 3-6 ข้อ
- รีวิว: คัดรีวิวจริงที่มีเนื้อหาเฉพาะ 3-8 อัน เช่น "ใส่เดินทั้งวันไม่กัดเท้า" ข้ามรีวิวกว้าง ๆ แบบ "ดี ส่งไว"
- ห้ามสรุปหรือแต่งรีวิวใหม่ คัดลอกตามจริง (ตัดคำหยาบ/ข้อมูลส่วนตัวออกได้)

## ตรวจคลิป (producer ทำทุกชิ้น)

| # | ตรวจ | ผ่านเมื่อ |
|---|---|---|
| 1 | รูป | ทุกรูปเป็นสินค้าชิ้นนั้น ไม่มีราคาในรูป ไม่แตก ไม่ยืดผิดสัดส่วน |
| 2 | กล่องหัวคลิป (ส้ม) | อ่านจบใน 2 วินาที ไม่ล้นกรอบ ไม่ใช่แค่ชื่อสินค้า |
| 3 | ซับ | ขึ้นตรงกับเสียง ไม่ค้างคำ ไม่ตัดกลางคำ ไม่มีสี่เหลี่ยมแทนตัวอักษร |
| 4 | เสียง | ได้ยินชัด ไม่ขาดกลางประโยค อ่านตัวเลขถูก |
| 5 | ความยาว | 15-30 วินาที (ถ้าสั้นกว่าเพราะบทสั้น ให้ generate ใหม่ ห้ามเติมความเงียบ) |
| 6 | ประโยคสุดท้าย | มีกล่องเหลืองชวนกดตะกร้า |
| 7 | ตำแหน่ง | ซับและหัวคลิปอยู่ในกรอบกลาง ไม่ชิดขอบล่างสุด (ที่แอปวางตะกร้าและแคปชัน) |
| 8 | จังหวะ | ไม่มีช่วงเงียบเกินครึ่งวินาทีระหว่างประโยค ไม่มีความเงียบยาวตอนจบ |
| 9 | ความต่าง | คลิปในวันเดียวกันไม่ซ้ำกันทั้งสไตล์ภาพ ธีมสี และประโยคเปิด (ดูคอลัมน์ style/theme ใน plan.json) |
| 10 | B-roll (ถ้ามี) | สินค้าในคลิป AI เหมือนรูปจริงทุกอย่าง ไม่มีตัวหนังสือมั่ว ไม่มีลายน้ำ |
