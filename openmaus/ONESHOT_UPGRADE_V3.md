# ใบสั่งงาน One-shot: อัปเกรดทีมเป็น V3

เจ้าของอนุมัติใบสั่งนี้ทั้งฉบับแล้ว ทำตามลำดับจนจบ ตัดสินใจเองได้ทุกเรื่องในกติกา
ถามเจ้าของเฉพาะ: ล็อกอิน/ยืนยันตัวตน, เงิน/เครดิตเกินงบ, การอนุมัติโพสต์

## กฎใหม่ที่สำคัญที่สุด: แยกงานเด็ดขาด
ทีมนี้ทำงาน Shopee เท่านั้น บัญชี Google และคอมเครื่องนี้มีงานอื่นของเจ้าของอยู่ ห้ามแตะ
- ไฟล์: เฉพาะใน C:\shopee-affiliate ห้ามแตะ AURIX, Downloads หรือโฟลเดอร์อื่น
- Google: เฉพาะ Google Flow ในโปรเจกต์ "Shopee Affiliate (ทีมบอท)" ที่ทีมสร้างเอง
  ห้ามเปิด/แก้/ลบโปรเจกต์ Flow อื่น ห้ามเข้า Gmail, Drive, Photos, YouTube, แชท Gemini, หน้าตั้งค่าบัญชี/แพ็กเกจ/การชำระเงิน
- เบราว์เซอร์: เฉพาะแท็บของงานนี้ ห้ามปิดหรือแก้แท็บของเจ้าของ
- เครดิต Flow: ไม่เกิน 60 เครดิต/วัน และใช้จากโควตารายเดือนไม่เกิน 400 (เหลือ 600 ไว้ให้เจ้าของ) ตั้ง 1 ผลลัพธ์ต่อคำสั่งเสมอ

## สิ่งที่เปลี่ยนใน V3
1. เสียงพากย์: ลองเสียง Gemini TTS ก่อน (ธรรมชาติกว่า ใช้คีย์ Gemini เดิม มีโควตารายวัน) ถ้าโควตาหมดระบบใช้เสียง Edge เดิมต่อเอง
2. B-roll: ใช้ Google Flow ทำคลิป 5-8 วินาทีจากรูปสินค้าจริง ระบบสุ่มให้ประมาณครึ่งหนึ่งของคลิปมี B-roll เพื่อเทียบผล
3. ระบบเรียนรู้เปรียบเทียบเพิ่ม: มี/ไม่มี B-roll และเสียง Gemini/Edge
4. แก้: เสียงล้มแล้ว retry 4 ครั้ง, คำลงท้ายตามเพศเสียง (ค่ะ/ครับ), บทต้องยาวพอให้คลิปถึง 15 วินาที
5. คำสั่งใหม่: python aff.py voicetest (ทำเสียงตัวอย่างทุกเสียงให้ฟังเทียบ)

## ขั้น 1 — อัปเดต
1. cd C:\shopee-affiliate แล้ว git pull จากนั้น git log -1 --oneline ใส่ในรายงาน
2. python -m unittest tests/test_pipeline.py ต้อง OK (21 tests) และ python aff.py doctor ต้องผ่าน
3. อ่านให้ครบ: openmaus/FLOW_BROLL.md, openmaus/LEARNING_LOOP.md, openmaus/QUALITY_STANDARD.md (ตรวจคลิป 11 ข้อ)
4. อัปเดตคำสั่งระบบของทั้ง 5 บอทด้วย "ส่วนที่ 0" ใหม่ (เพิ่มข้อ 10-11) และส่วนที่ 2 ของ shopee-producer ตาม openmaus/TEAM_SETUP.md
   ถ้าแก้เองไม่ได้ แนบข้อความใหม่ในรายงานให้เจ้าของวาง

## ขั้น 2 — ทดสอบเสียง
1. python aff.py voicetest
2. ส่งไฟล์ใน out\voicetest\ ทั้งหมดเข้าแอป Maus พร้อมผล OK/FAIL ของแต่ละเสียง
3. ถ้าเสียง Gemini ขึ้น FAIL ให้แนบข้อความ error เต็มในรายงาน (ระบบจะใช้เสียง Edge ต่อ ไม่ต้องหยุด)
4. ไม่ต้องรอเจ้าของฟัง ทำขั้นต่อไปได้เลย

## ขั้น 3 — ชุดงานวันนี้ (ใช้สินค้าที่ยังไม่ได้โพสต์)
1. ชิ้นไหนที่เจ้าของอนุมัติและโพสต์ไปแล้ว ไม่ต้องทำใหม่
2. ชิ้นที่ยังไม่ได้อนุมัติ: python aff.py generate --id <id> --force ทีละชิ้น (บทยาวขึ้น + คำลงท้ายถูก)
3. python aff.py daily --count 5 (ถ้ารันใหม่หลังเจ้าของอนุมัติบางชิ้นไปแล้ว ให้รัน python aff.py approve <เลขเดิม> อีกครั้ง)
4. เปิด out\<วันนี้>\BROLL_TODO.md แล้วทำ B-roll ตาม openmaus/FLOW_BROLL.md ทีละรายการ
   - ครั้งแรก: สร้างโปรเจกต์ Flow ชื่อ "Shopee Affiliate (ทีมบอท)"
   - จดเครดิตคงเหลือก่อนเริ่มและหลังจบลงรายงาน
5. python aff.py daily --count 5 อีกครั้ง เพื่อแทรก B-roll
6. ตรวจทุกชิ้นตาม QUALITY_STANDARD.md (คลิป 11 ข้อ + ข้อความ 6 ข้อ) และบันทึก lesson อย่างน้อย 2 ข้อ
   (1 ข้อเรื่องเสียง Gemini vs Edge, 1 ข้อเรื่อง B-roll จาก Flow) --source shopee-producer

## ขั้น 4 — ขออนุมัติ → หยุด
ส่งชุดอนุมัติเหมือน V2 (ตาราง APPROVAL.md + image.jpg + video.mp4 ทุกชิ้น + ผลตรวจ 17 ข้อ)
เพิ่ม 2 คอลัมน์ในรายงานของคุณ: เสียงที่ใช้ (gemini/edge) และ B-roll (มี/ไม่มี)
หลังเจ้าของตอบ ทำตามขั้น 6 ของ One-shot แรก บันทึกคำติชมของเจ้าของเป็น lesson --source owner
