## ลำดับการเริ่มงาน

| รอบ | งาน | ใครทำ | ผ่านเมื่อ |
|---|---|---|---|
| 1 | ติดตั้งบนเครื่อง | เจ้าของ + pc-care ตรวจ | `doctor` OK ทุกบรรทัด |
| 2 | เก็บข้อมูลจริง 5 ชิ้น | scout | ≥ 3 ชิ้น ready ข้อมูลตรงหน้าจริง |
| 3 | ผลิตคลิปจริง 3 ชิ้น | producer | เจ้าของดูบน iPhone แล้วพอใจ |
| 4 | โพสต์ Shopee Video ครั้งแรก | producer + publisher + เจ้าของ | คลิปขึ้น ตะกร้าถูกชิ้น มีบันทึกใน tracker |
| 5 | เปิดกิจวัตรประจำวัน (5 → 10 คลิป/วัน) | เจ้าของตั้งเวลาในแอป | 3 วันไม่มีปัญหา |
| 6 | Facebook Page | เจ้าของสร้างเพจ + publisher | โพสต์ในนามเพจ ลิงก์ในคอมเมนต์ถูกชิ้น |

## รูปแบบข้อความที่เจ้าของตอบบอท

| สถานการณ์ | พิมพ์ |
|---|---|
| อนุมัติทั้งชุด | `อนุมัติทั้งหมด` |
| อนุมัติบางชิ้น | `อนุมัติ 1,2,5` |
| ไม่อนุมัติพร้อมเหตุผล | `ไม่อนุมัติ 3 เพราะ รูปไม่ตรงสี` |
| โพสต์ Shopee เสร็จ | `โพสต์แล้ว 2` (แนบลิงก์คลิปถ้ามี) |
| ขอไฟล์แบบรวม | `ส่งแบบรวมเช้าเย็น` |
| หยุดทุกอย่าง | `หยุดทีม` แล้วปิดบอททุกตัวในแอป |
