# วงจรเรียนรู้และอัปเกรดตัวเอง (Learning Loop)

เป้าหมาย: ทีมเก่งขึ้นทุกสัปดาห์จาก 3 แหล่ง คือ **ผลจริง** (คลิก ออเดอร์ ค่าคอม), **การตรวจงานตัวเอง** และ **feedback ของเจ้าของ**
หลักการ: เปลี่ยนทีละอย่าง วัดผลก่อนเชื่อ เก็บหลักฐานทุกครั้ง ไม่แก้โค้ดเอง

## ไฟล์ความรู้ของทีม (data/learning/)

| ไฟล์ | คืออะไร | ใครเขียน |
|---|---|---|
| `playbook.md` | กติกาสไตล์ที่พิสูจน์แล้ว ระบบแทรกเข้า prompt เขียนคอนเทนต์ทุกครั้ง | shopee-analyst (รอบสัปดาห์) |
| `lessons.jsonl` | บันทึกบทเรียนรายวัน | ทุกบอท ผ่าน `python aff.py lesson "..." --tag ... --evidence ...` |
| `weights.json` / `insights.md` | ตัวเลขว่ามุมขาย สไตล์ภาพ ธีมสี เสียง หมวด แบบไหนทำเงิน | `python aff.py learn` |
| `proposals.md` | ข้อเสนอที่ต้องแก้โค้ด | ทุกบอท เขียน / เจ้าของส่งให้ Claude Code |

## ระบบทดลองเองอัตโนมัติ

ทุกคลิประบบสุ่มเลือก **สไตล์ภาพ** (framed / wide / quickcut) และ **ธีมสี** (shopee / night / mint / berry)
พอมีโพสต์ที่มียอดอย่างน้อย 3 โพสต์ต่อแบบ ระบบใช้แบบที่ทำเงินดีที่สุดประมาณ 70% และลองแบบอื่น 30% เพื่อเรียนรู้ต่อ
มุมขายที่ทำเงินดีสุดจะถูกบอกให้ Gemini รู้ในทุก prompt โดยอัตโนมัติ

## รอบรายวัน

**shopee-producer หลังผลิตเสร็จ** ตรวจงานตัวเองแล้วบันทึกบทเรียนอย่างน้อย 1 ข้อ เช่น
```
python aff.py lesson "สินค้าแฟชั่นใช้สไตล์ wide แล้วรองเท้าล้นกรอบ ควรใช้ framed" --tag video --evidence out/2026-11-22/03_xxx/video.mp4 --source shopee-producer
```
**ทุกบอท** เมื่อเจ้าของติหรือชมงาน ให้บันทึกเป็น lesson พร้อม `--source owner` ทันที

## รอบสัปดาห์ (shopee-analyst วันอาทิตย์)

1. `python aff.py learn` แล้วอ่าน `data/learning/insights.md`
2. อ่าน `lessons.jsonl` ของสัปดาห์
3. **ค้นคว้า 20 นาที:** เทรนด์คลิปขายของสั้นในไทยสัปดาห์นี้ (รูปแบบ Hook จังหวะตัดต่อ แคมเปญ Shopee ที่กำลังมา) จากแหล่งที่เชื่อถือได้ จดลิงก์ที่มา
4. อัปเดต `playbook.md`:
   - เพิ่มได้เฉพาะข้อที่มีหลักฐาน (ตัวเลขจาก insights ที่ proven = yes หรือ feedback เจ้าของ)
   - สิ่งที่ได้จากการค้นคว้ายังไม่ใช่กติกา ให้ใส่เป็น "ทดลอง: ..." ได้ไม่เกิน 2 ข้อต่อสัปดาห์ แล้ววัดผลสัปดาห์ถัดไป
   - ลบข้อที่ตัวเลขบอกว่าไม่ได้ผล ไฟล์ห้ามยาวเกิน 2,500 ตัวอักษร
5. เขียนข้อเสนอที่ต้องแก้โค้ดลง `proposals.md`
6. รายงานเจ้าของ: เรียนรู้อะไร เปลี่ยน playbook ข้อไหน ทดลองอะไรต่อสัปดาห์หน้า มีข้อเสนออะไรรอส่ง Claude Code

## บันไดอัปเกรดคุณภาพคลิป

| ขั้น | อะไร | เงื่อนไข |
|---|---|---|
| 1 (มีแล้ว) | รูปจริง 3 สไตล์ + 4 ธีม + ซับทีละคำ + ตัดช่วงเงียบ | ใช้ได้ทันที ฟรี |
| 2 | **B-roll จาก AI แบบเล่าเรื่อง**: ทำคลิป 5 วินาทีจากรูปสินค้าจริง ตาม `broll_prompts.txt` ในโฟลเดอร์งาน ระบบแทรกระหว่างรูปจริงเอง | ใช้เครื่องมือ image-to-video ที่เจ้าของมีสิทธิ์ใช้ฟรีเท่านั้น (เจ้าของบอกชื่อเครื่องมือ) ห้ามจ่ายเงิน ห้ามสมัครแพ็กเกจ |
| 3 | เครื่องมือเสียเงิน (เช่น API ทำวิดีโอ) | เฉพาะเมื่อ analyst แสดงตัวเลขว่า ค่าคอมต่อคลิปที่มี B-roll สูงกว่าค่าใช้จ่ายต่อคลิปชัดเจน และเจ้าของอนุมัติ |

**กติกา B-roll (ขั้น 2):**
- ใช้รูปสินค้าจริงรูปที่ 1 เป็นภาพอ้างอิงเสมอ วาง prompt จาก `broll_prompts.txt` ตามตัวอักษร
- เปิดคลิปที่ได้ดูทั้งคลิป: ถ้าสินค้ารูปทรง สี โลโก้ หรือจำนวนชิ้นเพี้ยนจากรูปจริง **ทิ้งทันที** (คลิปไม่ตรงสินค้า = ผิดกฎ Shopee)
- ห้ามมีคน/มือที่ดูผิดธรรมชาติ ตัวหนังสือมั่ว หรือลายน้ำของเครื่องมือ
- บันทึกเป็น `media/<id>/clips/broll_1.mp4`, `broll_2.mp4` แล้วรัน `python aff.py daily` ใหม่ ระบบจะแทรกให้เอง
- ทุกคลิปที่มี B-roll ยังต้องเปิดป้าย "เนื้อหาที่สร้างโดย AI" ตอนโพสต์

## สิ่งที่ห้ามในการอัปเกรดตัวเอง

- ห้ามแก้ไฟล์โค้ดและ `prompts/` (ข้อเสนอให้เขียนใน proposals.md)
- ห้ามเปลี่ยนกฎความจริง กฎความปลอดภัยบัญชี หรือเกณฑ์อนุมัติเพื่อให้ "ได้ผลดีขึ้น"
- ห้ามเปลี่ยนหลายอย่างพร้อมกันในสัปดาห์เดียว (วัดผลไม่ได้)
- ห้ามสรุปจากโพสต์น้อยกว่า 3 โพสต์ต่อแบบ
