# รอบที่ 3 — ผลิตคลิปจริงชุดทดลอง 3 ชิ้น

ผู้ทำ: **shopee-producer**  ต้องผ่านรอบที่ 2 ก่อน

ข้อความสั่งงาน:
```
ใบสั่งงานรอบที่ 3: ผลิตชุดทดลอง 3 ชิ้น
- รัน python aff.py daily --count 3
- ตรวจทุกชิ้นตาม openmaus/QUALITY_STANDARD.md หมวด "ตรวจคลิป" และ "ตรวจข้อความ" ทุกข้อ
- ส่งเข้าแอป Maus: ตารางจาก out/<วันนี้>/APPROVAL.md, ไฟล์ video.mp4 และ image.jpg ทั้ง 3 ชิ้น,
  ตารางผลตรวจ ชิ้น / ข้อที่ไม่ผ่าน / เหตุผล
- รายงานเพิ่ม 2 อย่าง: เสียงพากย์ทำงานไหม (ใน log มี "TTS failed" หรือไม่) และใช้เวลาผลิตชิ้นละกี่นาที
- ยังไม่ต้องรัน approve รอเจ้าของดูก่อน
```

เจ้าของตรวจบน iPhone:
- ดูคลิปเต็มจอ: ซับอ่านทันไหม ตรงเสียงไหม เสียงพากย์ฟังเป็นธรรมชาติไหม รูปชัดไหม
- เปิดแอป Shopee > เมนูสร้าง Shopee Video > เลือกคลิปนี้ (ยังไม่ต้องโพสต์) ดูว่าปุ่มหรือตะกร้าบังกล่องหัวคลิปหรือซับไหม

ผ่านเมื่อ: เจ้าของพอใจทั้ง 3 ชิ้น
ไม่ผ่าน: ส่งคลิป + สิ่งที่ไม่ชอบ (เช่น "ซับเล็กไป", "เสียงเร็วไป", "หัวคลิปโดนบัง") ให้ Claude Code ปรับ แล้วทำรอบนี้ใหม่
