# รอบที่ 2 — scout ทดลองเก็บข้อมูลจริง 5 ชิ้น

ผู้ทำ: **shopee-scout**  ก่อนเริ่ม เจ้าของเปิด Chrome ล็อกอิน affiliate.shopee.co.th ทิ้งไว้

ข้อความสั่งงาน (คัดลอกส่งให้ scout):
```
ใบสั่งงานรอบที่ 2: ทดลองเก็บข้อมูลจริง 5 ชิ้น
- อ่าน openmaus/QUALITY_STANDARD.md หมวด "รูปสินค้า" และ "ข้อมูลสินค้า" ก่อนเริ่ม
- รัน python aff.py todo แล้วทำ 5 ชิ้นแรกในรายการ ทีละชิ้น
- เขียนผลลง data/inbox/scout_pilot.txt ตามรูปแบบ data/inbox/TEMPLATE.txt
- รัน python aff.py import
- รายงาน: ตาราง ชิ้น / Extra Comm / จำนวนรูปที่ได้ / status หลัง import / ปัญหาที่เจอ
  และแนบภาพหน้าจอหน้าสินค้า 1 ชิ้นที่แสดงช่อง Extra Comm ให้เจ้าของเทียบ
- ห้ามทำเกิน 5 ชิ้นในรอบนี้
```

เจ้าของตรวจ:
- เปิดโฟลเดอร์ `C:\shopee-affiliate\media\<รหัสสินค้า>\` ดูรูปว่าเป็นสินค้าจริงชิ้นนั้น ขนาดเต็ม ไม่มีราคาในรูป
- เปิด `data\products\<รหัสสินค้า>.json` ดูว่า Extra Comm, จุดเด่น, รีวิว ตรงกับหน้าสินค้าจริง

ผ่านเมื่อ: อย่างน้อย 3 ชิ้น status = ready และข้อมูลตรงกับหน้าจริงทุกช่อง
ไม่ผ่าน: บอกข้อที่ผิดกับ scout ให้แก้ หรือส่งให้ Claude Code ถ้าเป็นปัญหาของคำสั่ง import
