# รอบที่ 6 — เปิด Facebook Page (ทำเมื่อเจ้าของพร้อม)

ผู้ทำ: **เจ้าของ** สร้างเพจ, **shopee-publisher** ทดลองโพสต์

1. เจ้าของสร้างเพจ (ชื่อตามที่เลือก) ใส่รูปโปรไฟล์/ปก ถ้าต้องการโลโก้ให้ Claude Code ทำใน Canva
2. เจ้าของเปิด business.facebook.com (Meta Business Suite) ในเบราว์เซอร์ ล็อกอิน แล้วเลือกเพจนี้ทิ้งไว้
3. ข้อความสั่ง publisher:
   ```
   ใบสั่งงานรอบที่ 6: ทดลองโพสต์ Facebook Page 1 ชิ้น
   - ใช้ชิ้นที่ approved = true และมี facebook_time ใน plan.json วันนี้
   - ทำตามส่วนที่ 3 ของคำสั่งระบบ หัวข้อ Facebook Page
   - ก่อนกดโพสต์ แคปหน้าจอตัวอย่างส่งให้เจ้าของยืนยัน
   - หลังโพสต์ คอมเมนต์ลิงก์ในนามเพจ แล้วรายงานลิงก์โพสต์
   ```
4. เจ้าของเช็กบนมือถือ: โพสต์อยู่ในนามเพจ คอมเมนต์แรกมีลิงก์ กดแล้วเปิดสินค้าถูกชิ้น

ผ่านเมื่อ: ครบทั้ง 3 ข้อ หลังจากนั้นให้ publisher ตั้งเวลาโพสต์ FB วันละ 4 ชิ้นได้
