## ห้ามเด็ดขาด
- ห้ามล็อกอิน พิมพ์รหัสผ่าน OTP หรือรหัสยืนยัน ห้ามสลับบัญชี ใช้เฉพาะหน้าต่างที่เจ้าของล็อกอินไว้
- ห้ามเปิด อ่าน คัดลอก หรือแคปหน้าจอไฟล์ .env และคีย์ใด ๆ
- ห้ามซื้อ สั่งสินค้า กดลิงก์ตัวเองเพื่อซื้อ หรือแตะหน้าธนาคาร ภาษี การจ่ายเงินของ Shopee
- ห้ามแต่งข้อมูลสินค้า ใช้รูปที่ไม่ใช่สินค้าชิ้นนั้น หรือแก้ข้อความให้อ้างว่าเคยใช้/เคยซื้อ
- ห้ามคอมเมนต์หรือแปะลิงก์ในเพจ กลุ่ม หรือโพสต์ของคนอื่น
- ห้ามแก้ไฟล์โค้ด (aff.py, affiliate/, prompts/, tests/) ถ้าคำสั่ง error ให้รายงานข้อความ error ทั้งหมด
- ห้ามเปิดหน้าสินค้าเกิน 40 หน้าต่อวัน ห้ามเปิดหลายแท็บพร้อมกันเพื่อเร่งงาน ทำด้วยความเร็วแบบคน

## ขั้น 1 — ตรวจความพร้อม และเติมส่วนที่ขาด
ตรวจทีละข้อ ทำตารางสถานะ (พร้อม / ทำให้แล้ว / รอเจ้าของ)
1. โฟลเดอร์ C:\shopee-affiliate มีโปรเจกต์ไหม
   ไม่มี → winget install -e --id Git.Git (ถ้ายังไม่มี git) แล้ว
   git clone -b claude/awesome-faraday-pj20x4 https://github.com/diamondv1966/hello-world C:\shopee-affiliate
   มีแล้ว → cd C:\shopee-affiliate แล้ว git pull
2. รัน powershell -ExecutionPolicy Bypass -File setup.ps1 ในโฟลเดอร์นั้น
   ถ้ามีหน้าต่าง UAC ขอสิทธิ์ผู้ดูแล → หยุด (จุดที่ 1) ให้เจ้าของกด Yes แล้วทำต่อ
3. รัน python aff.py doctor
   - ถ้าขึ้น MISSING GEMINI_API_KEY → หยุด (จุดที่ 2) แจ้งเจ้าของว่า
     "เปิดไฟล์ C:\shopee-affiliate\.env ด้วย Notepad แล้ววางคีย์ Gemini ต่อท้าย GEMINI_API_KEY= (คีย์เดียวกับ AURIX) แล้วบันทึก"
     รอคำว่า "ใส่คีย์แล้ว" แล้วรัน doctor ใหม่ (ห้ามเปิดดูไฟล์ .env เอง)
   - MISSING อื่น ๆ → รัน setup.ps1 ซ้ำ 1 ครั้ง ยังไม่ผ่านให้รายงาน
4. รัน python -m unittest tests/test_pipeline.py ต้องขึ้น OK
5. หน้าต่าง Chrome affiliate.shopee.co.th ล็อกอินอยู่ไหม เห็นหน้าสินค้า/ข้อเสนอ และอัตราค่าคอมไหม
   ไม่ล็อกอิน → หยุด (จุดที่ 3) ขอให้เจ้าของล็อกอิน
6. แอป Maus ส่งไฟล์ถึงเจ้าของได้ไหม: ส่งไฟล์ README.md 1 ไฟล์ทดสอบ พร้อมข้อความ "ทดสอบส่งไฟล์จากทีม Shopee"
7. Facebook Page: มีหน้าต่าง business.facebook.com ที่เลือกเพจไว้ไหม (ไม่มี = ข้ามงาน Facebook วันนี้ ไม่ต้องหยุด)
8. การตั้งค่าพลังงาน: เครื่องจะหลับเมื่อไหร่ ถ้าหลับก่อน 23:00 ให้ใส่ในรายงาน (ห้ามเปลี่ยนเอง)
9. อ่านไฟล์เหล่านี้ให้ครบก่อนไปขั้น 2:
   openmaus/TEAM_SETUP.md, openmaus/QUALITY_STANDARD.md, docs/PLAN.md, data/inbox/TEMPLATE.txt, data/inbox/LINKS_TO_SCOUT.md

## ขั้น 2 — ตั้งทีม 5 บอท

## ขั้น 3 — หาสินค้าและเก็บข้อมูลจริง (บทบาท shopee-scout)
เป้าหมายวันนี้: สินค้า status = ready อย่างน้อย 8 ชิ้น
1. python aff.py todo → ทำ 6 ชิ้นแรก (ลิงก์ Affiliate มีอยู่แล้ว เก็บข้อมูลและรูปเพิ่ม)
2. หาสินค้าใหม่อีกอย่างน้อย 6 ชิ้นในหน้าสินค้า/ข้อเสนอของ Shopee Affiliate
   เกณฑ์: Extra Comm ≥ 8%, เรตติ้ง ≥ 4.7, ขายแล้ว ≥ 300, ราคา 150-3,000 บาท, ไม่เกิน 2 ชิ้นต่อหมวด
   ให้น้ำหนัก: สินค้าร่วมแคมเปญ 12.12, ของหน้าหนาว, ของขวัญปีใหม่, ของใช้ในบ้าน, เครื่องมือ
   ไม่เอา: อาหารเสริม ยา เครื่องสำอางอ้างผลลัพธ์ อาวุธ บุหรี่ไฟฟ้า แอลกอฮอล์ นมผงเด็ก ของก๊อป หมวดค่าคอม 0%
   กด "รับลิงก์" เอาลิงก์สั้น s.shopee.co.th/...
3. ทุกชิ้นเก็บตาม data/inbox/TEMPLATE.txt และ QUALITY_STANDARD.md หมวด "รูปสินค้า" "ข้อมูลสินค้า"
   รูป: คลิกขวารูปใหญ่ > คัดลอกที่อยู่รูปภาพ 3-5 รูป รูปแรกคือสินค้าชัดที่สุด ไม่เอารูปที่มีราคาเขียนอยู่
   รีวิว: คัดลอกรีวิวจริงที่มีเนื้อหา 3-8 อัน
4. บันทึกเป็น data/inbox/scout_<วันที่>.txt แล้วรัน python aff.py import
5. ดูผล import: ชิ้นที่รูปดาวน์โหลดไม่ได้หรือรูปเล็กเกิน ให้เก็บรูปใหม่ 1 รอบ

## ขั้น 4 — ผลิตและตรวจคุณภาพ (บทบาท shopee-producer)
1. วันแรกทำ 5 ชิ้น: python aff.py daily --count 5
   ถ้าขึ้น "Gemini free quota used up" ให้รอ 60 นาทีแล้วรันใหม่
   ถ้าใน log มี "TTS failed" ให้รันใหม่ 1 ครั้ง ยังไม่หายให้ใส่ในรายงาน (คลิปจะไม่มีเสียง ห้ามส่งให้เจ้าของโพสต์)
2. เปิด out/<วันนี้>/ ตรวจทุกชิ้นตาม QUALITY_STANDARD.md หมวด "ตรวจคลิป" 7 ข้อ และ "ตรวจข้อความ" 6 ข้อ
   - ดูคลิปจนจบทุกชิ้น และเปิดลิงก์ใน link.txt ว่าเปิดสินค้าตรงชิ้น (เปิดดูเท่านั้น ห้ามกดซื้อ)
   - ไม่ผ่านเพราะข้อความ → python aff.py generate --id <id> --force แล้ว python aff.py daily --count 5 ใหม่
   - ไม่ผ่านเพราะรูป → ตัดชิ้นนั้นออกจากชุด และบันทึกไว้ให้ scout เก็บรูปใหม่พรุ่งนี้

## ขั้น 5 — ขออนุมัติ → หยุด (จุดที่ 4)
ส่งเข้าแอป Maus ข้อความเดียว:
- หัวข้อ "ชุดอนุมัติวันที่ <วันที่> (ชุดแรก)"
- ตารางจาก out/<วันนี้>/APPROVAL.md (มีกลุ่มลูกค้า มุมขาย เวลา และรูปแบบโพสต์ Facebook พร้อมเหตุผล)
- ไฟล์ image.jpg ทุกชิ้น และ video.mp4 ทุกชิ้น
- ตารางผลตรวจของคุณ: ชิ้น / ผ่าน-ไม่ผ่าน / หมายเหตุ
- วิธีตอบ: "อนุมัติทั้งหมด" หรือ "อนุมัติ 1,3" หรือ "ไม่อนุมัติ 2 เพราะ ..."

## ขั้น 6 — หลังอนุมัติ (บทบาท shopee-publisher)
1. python aff.py approve all  หรือ  python aff.py approve <เลข> --reject-others  ตามที่เจ้าของตอบ
2. Shopee Video (วันแรกส่งทันที ไม่ต้องรอเวลาในตาราง): ส่งเข้าแอป Maus ทีละชิ้น 1 ข้อความต่อชิ้น
   video.mp4 + ข้อความ shopee_caption.txt (พร้อมคัดลอก) + ชื่อสินค้า + ลิงก์จาก link.txt
   + เตือน: ปักตะกร้า 1 ชิ้นให้ตรงลิงก์ / เปิดป้าย "เนื้อหาที่สร้างโดย AI" / โพสต์ห่างกันอย่างน้อย 20 นาที
   เจ้าของตอบ "โพสต์แล้ว N" → python aff.py posted N shopee_video
3. Facebook Page (เฉพาะถ้าขั้น 1 ข้อ 7 พร้อม): ชิ้นที่มี facebook_time ใน plan.json
   โพสต์ตาม facebook_type (video = video.mp4 แบบ Reels, image = image.jpg) พร้อมข้อความ fb_post.txt ในนามเพจ
   โพสต์แรกของทีม: แคปหน้าจอตัวอย่างให้เจ้าของยืนยันก่อนกดโพสต์
   ห้ามใส่ลิงก์ในตัวโพสต์ หลังโพสต์ขึ้น 1-3 นาที คอมเมนต์ข้อความใน fb_first_comment.txt ในนามเพจ
   ชิ้นที่เหลือตั้งเวลาตาม facebook_time ใน Meta Business Suite แล้ว python aff.py posted N facebook <ลิงก์โพสต์>
