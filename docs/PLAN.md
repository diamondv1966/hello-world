## สิ่งที่ตัดสินใจแล้ว

| เรื่อง | ตัดสินใจ |
|---|---|
| เป้าหมาย | รายได้ของตัวเอง เริ่มวันนี้ แล้วเดินเองทุกวัน |
| ช่องทาง | Shopee Video (10 คลิป/วัน, เจ้าของกดโพสต์จาก iPhone) + Facebook Page (4 โพสต์/วัน เมื่อเปิดเพจแล้ว บอทโพสต์เอง) |
| รูปแบบ | faceless ผสม: คลิปรูปสินค้าจริง + เสียงพากย์ AI + ตัวหนังสือ และโพสต์ภาพ + ข้อความ |
| เสียง | AI เลือกเสียงชายหรือหญิงตามสินค้า (edge-tts ฟรี) |
| สินค้า | ทุกหมวด คัดจากค่าคอมเป็นบาทต่อออเดอร์ ≥ 20 บาท (ราคา x (2% + Extra Comm%)) ไม่ใช่จากเปอร์เซ็นต์ ส่วนเรตติ้งและยอดขายให้ scout วิเคราะห์ (ค่าเริ่ม ≥ 4.7 ดาว ≥ 300 ชิ้น) |

| ทีมบอท | Maus ชุดใหม่ 5 ตัว แยกจากทีม AURIX ดูรายละเอียดใน `openmaus/` |
| การอนุมัติ | บอทตรวจเองทุกชิ้น แล้วส่งชุดอนุมัติเข้าแอป Maus เจ้าของสุ่มตรวจและอนุมัติ |
| Shopee | บอทไม่ล็อกอิน ใช้หน้าต่างที่เจ้าของเปิดไว้ |
| ข้อมูล (H) | เก็บในไฟล์ `data/tracker/posts.csv` 41 คอลัมน์ตาม PDF เปิดด้วย Excel ได้ ไม่ต้องมีเซิร์ฟเวอร์ |
| ความเสี่ยง (I) | ห้ามอ้างว่าเคยใช้, เปิดป้าย AI ทุกคลิป, ไม่ดูดคลิปคนอื่น, โพสต์ไม่เกินตาราง ระบบตรวจให้อัตโนมัติ |

## วิธีที่ระบบทำงานแต่ละวัน

```
07:15 pc-care     ตรวจเครื่อง หน้าต่าง และพื้นที่ดิสก์
07:30 scout       เติมข้อมูลสินค้า / หาสินค้าใหม่ -> data/inbox/*.txt -> python aff.py import
08:00 producer    run_daily.bat -> คัด 10 ชิ้น -> Gemini เขียน -> ตรวจกฎ -> ทำคลิป + ภาพ -> ตรวจเอง -> ส่งอนุมัติในแอป Maus
      เจ้าของ     กดอนุมัติในแอป Maus (สุ่มดูบางชิ้น)
08:40-21:35 publisher  โพสต์ Shopee Video ตามเวลา, ตั้งเวลาโพสต์ Facebook ใน Meta Business Suite
20:00 pc-care     ตรวจรอบเย็น
22:30 analyst     เก็บยอด -> tracker -> รายงานสั้นเข้าแอป Maus
```

ถ้าเครื่องไม่ได้เปิดทั้งวัน: Facebook ตั้งเวลาล่วงหน้าได้ทั้งหมดในรอบเช้า ส่วน Shopee Video ให้ publisher โพสต์เป็น 2 ช่วงที่เครื่องเปิด (เช้า/ค่ำ) เว้นกันชิ้นละ 20-30 นาที

## กลยุทธ์การตลาด (ข้อ 30)

**ตัวตนเพจ:** เพจ "คัดของคุ้ม" แบบ faceless พูดเหมือนเพื่อนที่ชอบหาของดี ไม่ใช่ร้านค้า
ชื่อที่แนะนำ (เลือก 1): `คัดของคุ้ม`, `ของดีบอกต่อ`, `ป้ายยาของใช้คุ้ม ๆ`
ไม่ควรใช้ชื่อที่สื่อว่าใช้เองทุกชิ้น เพราะเป็นคอนเทนต์ AI

**ทำไม Shopee Video ก่อน:** คนดูอยู่ในแอปเพื่อซื้ออยู่แล้ว คลิปที่ติดตะกร้าสินค้าที่ยังไม่มีคู่แข่งจะไปโผล่ในหน้าสินค้า ยอดวิวน้อยก็ขายได้ (จาก PDF บทที่ 3)

**มุมขาย 6 แบบ** (AI เลือกให้ตามสินค้า ระบบบันทึกไว้ในช่อง `utm_content` เพื่อดูว่าแบบไหนทำเงิน)

| มุม | ใช้กับ | ตัวอย่าง Hook |
|---|---|---|
| problem_solution | ของใช้ในบ้าน เครื่องมือ ทำความสะอาด | "หน้าฝนทีไร พื้นหน้าบ้านเขียวทุกที" |
| value_deal | ของกิน ของใช้สิ้นเปลือง แพ็กคู่ | "ทิชชู่ 5 แพ็กแบบแขวน ประหยัดที่บนโต๊ะ" |
| style_pick | รองเท้า เสื้อผ้า กระเป๋า | "ฮู้ดสกรีนอกตัวนี้ใส่ได้ทั้งไปเรียนและเที่ยว" |
| gift_idea | ของขวัญปีใหม่ | "ของขวัญจับฉลากงบไม่เกิน 300" |
| how_it_works | อุปกรณ์ไฟฟ้า สว่าน เครื่องตัดหญ้า | "สว่าน 2 ระบบ เปลี่ยนโหมดยังไง" |
| seasonal | หน้าหนาว 12.12 ปีใหม่ | "ลมหนาวมาแล้ว ของที่ควรมีติดบ้าน" |

**ปฏิทินที่กำลังจะมา:** 25 พ.ย. (เงินเดือนออก) → **12.12** (แคมเปญใหญ่ ให้ scout เน้นสินค้าที่ร่วมแคมเปญตั้งแต่ 5 ธ.ค.) → คริสต์มาส/ปีใหม่ (ของขวัญ) → 15 ม.ค. (เงินเดือน + ลดราคากลางเดือน)
บันทึกวันแคมเปญจริงได้ที่หน้า campaign ของ Shopee Affiliate

**เวลาโพสต์:** ช่วงที่คนไทยเล่นมือถือมากคือพักเที่ยงและ 19:00-22:00 ตารางใน `affiliate/config.py` วางคลิปส่วนใหญ่ไว้ช่วงนั้น เปลี่ยนได้

**ทำให้ดูเป็นคนจริง (แต่ไม่หลอก):** ประโยคสั้น ภาษาพูด เปิดเรื่องไม่ซ้ำกัน จบโพสต์ FB ด้วยคำถามชวนคอมเมนต์ อ้างรีวิวว่าเป็น "คนรีวิวบอกว่า" ไม่อ้างว่าใช้เอง
เหตุผล: Shopee สั่งให้เปิดป้าย AI และห้ามบิดเบือนสินค้า ถ้าโดนรายงานว่าหลอก บัญชี Affiliate เสี่ยงโดนระงับ ซึ่งเสียหายกว่ายอดที่ได้เพิ่มมาก

## ความเสี่ยงที่ยังเหลือ (บอกตรง ๆ)

1. **บอทควบคุม Shopee:** ข้อตกลง Shopee TH (อ้างโดย Involve Asia) ห้ามใช้ robot/automated tools ใช้หน้าต่างที่เจ้าของเปิด + ความเร็วแบบคน + โพสต์ไม่เกินตาราง ช่วยลดความเสี่ยงแต่ไม่ได้ทำให้เป็นศูนย์
2. **Shopee Video ต้องกดโพสต์เองบน iPhone:** ไม่มีช่องทางโพสต์ผ่านเว็บที่ยืนยันได้ และบอทควบคุม iPhone ไม่ได้ บอทจึงส่งคลิป + แคปชัน + ลิงก์เข้าแอป Maus ให้เจ้าของโพสต์ (ชิ้นละประมาณ 1 นาที)
3. **โควตาฟรีของ Gemini:** ถ้าหมด ระบบหยุดและทำต่อรอบถัดไปได้ ไม่เปิดใช้แบบเสียเงินเอง
4. **ผลลัพธ์:** PDF บันทึกว่ามีคนโพสต์ 70 คลิป/วัน 30 วัน ได้ค่าคอม 723 บาท ปริมาณอย่างเดียวไม่พอ ตัวที่ทำเงินคือการคัดสินค้า Extra Comm สูงและหมวดที่ขายได้จริง จึงต้องให้ analyst ทำงานทุกคืน
5. **ภาษี:** รายได้ค่าคอมเป็นเงินได้ ม.40(2) ยื่น ภ.ง.ด.90/91 ช่วง ม.ค.-มี.ค. ถ้ารวมทั้งปีเกิน 60,000 บาท (บุคคลโสด) Shopee ส่งข้อมูลให้สรรพากรอยู่แล้ว
